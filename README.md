# 五張撲克牌遊戲系統 (Five Card Draw Poker)

**開發者：** 魏允鴻 (學號：1131417)  
**開發環境：** C# Windows Forms (.NET)

## 專案簡介
本專案為一個基於 C# Windows Forms 開發的「五張撲克牌 (5-Card Draw)」模擬遊戲。系統不僅完整還原了標準撲克牌的發牌、換牌與牌型判斷邏輯，還加入了**資金下注系統**、依照真實賠率計算的**獎金機制**，以及完善的**無滑鼠操作支援**。

此外，為了豐富使用者體驗，系統實作了頂端選單 (MenuStrip)，提供自訂視窗色彩、匯出遊戲歷史紀錄等進階功能。

---

## 系統功能特色
1. **完整的撲克牌遊戲流程**：支援洗牌、發牌、點擊蓋牌（選擇棄牌），以及單次換牌功能。
2. **動態下注與資金管理**：玩家初始資金為 1,000,000 元，需設定押注金額才可發牌，並根據最終牌型（如：皇家同花順 250 倍、葫蘆 9 倍等）即時結算獎金。
3. **無滑鼠操作支援**：完美設定 Tab 鍵順序 (Tab Index) 與 Enter 鍵觸發，玩家可全程使用鍵盤順暢遊玩。
4. **選單進階功能 (MenuStrip)**：
   * **調色功能**：呼叫 `ColorDialog`，一鍵更改視窗背景與所有按鈕的顏色（使用遞迴搜尋控制項實作）。
   * **輸出紀錄**：結合 `SaveFileDialog` 與 `System.IO`，將玩家每一局的下注金額、牌型結果與結餘匯出為 `.txt` 文字檔。
   * **關於系統**：顯示遊戲開發者資訊與基本玩法說明。
5. **開發者測試快捷鍵**：為了方便測試高賠率牌型，在發牌後按下指定鍵盤按鍵，可直接召喚對應大牌（Q: 皇家同花順 / W: 同花順 / E: 同花 / R: 鐵支 / T: 葫蘆 / Y: 三條）。

---

## 執行說明與遊玩步驟

### 基礎玩法：
1. **【設定下注】**：在「下注」區塊的 `押注金額` 欄位輸入你想下的注碼（預設為 500）。
2. **【確認押注】**：點擊 **「押注」** 按鈕，系統會扣除總資金並解鎖發牌功能。
3. **【發放手牌】**：點擊 **「發牌」** 按鈕，牌桌上會隨機發出 5 張撲克牌。
4. **【選擇換牌】**：若對手牌不滿意，請用滑鼠點擊想換掉的牌（牌面會翻轉朝下），接著點選 **「換牌」** 按鈕抽取新牌（每局限換一次）。
5. **【結算獎金】**：點擊 **「判斷牌型」** 按鈕，系統會自動比對牌型，顯示結果並發放對應賠率的獎金，隨後即可開始下一局。

### 開發者測試模式 (快捷鍵)：
在點擊「發牌」後、尚未點擊「換牌」或「判斷牌型」前，可按鍵盤按鍵進行牌型測試：
* `Q` 鍵 👉 直接取得 **皇家同花順** (賠率 250)
* `W` 鍵 👉 直接取得 **同花順** (賠率 50)
* `E` 鍵 👉 直接取得 **同花** (賠率 6)
* `R` 鍵 👉 直接取得 **鐵支 (四條)** (賠率 25)
* `T` 鍵 👉 直接取得 **葫蘆** (賠率 9)
* `Y` 鍵 👉 直接取得 **三條** (賠率 3)
